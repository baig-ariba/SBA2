# SBA Lab 2

### Accessibility Challenges
The accessibilty challange for the most part was semantic html use withe aria labels. I addressed them by trying to use semantic html as much as possible and adding in ARIA semantics whereever semantichtml was not sufficient.

### Responsive Design and Accessibility
The responsiveness of the webpage was checed using the inspect tool from the webpage while trying our different pixels resolution and breakpoints. The accessibility of the webpage was checked using extension and putting in as much accessibility aids as possible in the html file.

### Tools and Resources
The tools that I used were the html w3 school website for the tags, WebAIM for sontract and a webAIM extension on google chrome to check for the level of accessibilty.
